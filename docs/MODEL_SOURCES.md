# MODEL_SOURCES.md - Inventaris dan Atribusi Model 3D

Dokumen inventaris dan lisensi model 3D untuk Katalog Part Tooling Manufaktur Otomotif sesuai ketentuan AGENTS.md.

## 1. Aturan Lisensi dan Sumber Model

- Lisensi yang diizinkan: `CC0`, `CC-BY-4.0`, `CC-BY-SA-4.0`, `Public Domain`, `Apache-2.0`, `MIT`.
- Format file: `.glb` (glTF binary) disimpan secara lokal di `/public/models/`.
- Poster thumbnail: `.webp` atau fallback disimpan di `/public/posters/`.
- Atribusi wajib ditampilkan di UI Detail Panel: nama model, pembuat (author), lisensi, dan tautan sumber.
- Status model: model parametrik/prosedural internal ditandai `isPlaceholder: true` dan dilabeli "Model ilustrasi".
